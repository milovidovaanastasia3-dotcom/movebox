# movebox
MOVEBOX — это онлайн-платформа для обучения танцам, где каждый желающий может изучать новые движения и хореографии, развивать свои навыки и заниматься в удобном темпе. Проект объединяет обучающие видео, разные танцевальные направления и программы для любого уровня подготовки. Наша цель — сделать танцы доступными и интересными для каждого.
